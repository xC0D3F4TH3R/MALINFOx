Step 1: Provision Oracle Cloud Free Tier VM

bash

- Shape: VM.Standard.A1.Flex (ARM)
- OCPUs: 4
- Memory: 24 GB
- Boot volume: 200 GB
- OS: Ubuntu 22.04 or 24.04 Minimal
- SSH keys: Add your public key
- Network: Allow ports 22, 80, 443 (ingress)

SSH in

Step 2: Configure KVM for Nested Virtualization (Required for VM Sandbox)

bash

cat /sys/module/kvm_intel/parameters/nested  # or kvm_amd for AMD
Should return 'Y' — if not, Oracle ARM supports it by default

Verify KVM access
ls -la /dev/kvm
Should be accessible (crw-rw---- root kvm)




Step 3: Setup DuckDNS Domain

bash
1. Go to https://www.duckdns.org → Sign in with GitHub
2. Create subdomain: malinfo (or your choice) → malinfo.duckdns.org
3. Note your token

On the VM, create auto-update script:
sudo tee /usr/local/bin/duckdns-update.sh > /dev/null <<'EOF'
#!/bin/bash
DOMAIN="malinfo"
TOKEN="YOUR_DUCKDNS_TOKEN_HERE"
curl -s "https://www.duckdns.org/update?domains=${DOMAIN}&token=${TOKEN}&ip="
EOF

sudo chmod +x /usr/local/bin/duckdns-update.sh

Run once to test
/usr/local/bin/duckdns-update.sh

Add to crontab (every 5 min)
(crontab -l 2>/dev/null; echo "*/5 * * * * /usr/local/bin/duckdns-update.sh") | crontab -




Step 4: Setup Cloudflare Tunnel (Free TLS + WAF + DDoS)

bash
On the VM, install cloudflared
curl -L --output cloudflared.deb https://github.com/cloudflare/cloudflared/releases/latest/download/cloudflared-linux-arm64.deb
sudo dpkg -i cloudflared.deb

Authenticate (opens browser — run on your LOCAL machine, not the VM):
cloudflared tunnel login

Instead, create tunnel via dashboard (easier):
1. Go to https://dash.cloudflare.com → Zero Trust → Networks → Tunnels
2. Create tunnel → Name: malinfo → Save
3. Copy the Tunnel ID (e.g., abc123...xyz)
4. Public hostname: malinfo.duckdns.org → HTTPS → localhost:443
5. Save

On VM, create config:
sudo mkdir -p /etc/cloudflared
sudo tee /etc/cloudflared/config.yml > /dev/null <<EOF
tunnel: YOUR_TUNNEL_ID_HERE
credentials-file: /etc/cloudflared/YOUR_TUNNEL_ID_HERE.json
ingress:
  - hostname: malinfo.duckdns.org
    service: https://localhost:443
    originRequest:
      noTLSVerify: true
  - service: http_status:404
EOF

Download credentials file from dashboard → Save as /etc/cloudflared/<TUNNEL_ID>.json

Install as service
sudo cloudflared service install
sudo systemctl enable --now cloudflared
sudo systemctl status cloudflared

Troubleshooting Quick Reference

Issue: libvirt not found
Fix: sudo apt install -y libvirt-daemon-system qemu-kvm && sudo usermod -aG libvirt,kvm $USER && newgrp docker
────────────────────────────────────────
Issue: VM template stuck "building"
Fix: Check make logs SERVICE=backend — ensure nested virt enabled
────────────────────────────────────────
Issue: Cloudflare Tunnel 502
Fix: Verify cloudflared service running; check config.yml points to https://localhost:443
────────────────────────────────────────
Issue: Email not sending
Fix: Verify Gmail App Password (not regular password); check SMTP_PORT=587, SMTP_TLS=true
────────────────────────────────────────
Issue: WebSocket not connecting
Fix: Nginx config must have proxy_set_header Upgrade $http_upgrade; proxy_set_header Connection "upgrade";
────────────────────────────────────────
Issue: Out of disk
Fix: docker system prune -af --volumes then check /opt/malinfo/storage
